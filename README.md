# Esraa Ibrahim: portfolio (static site for GitHub Pages)

## Deploy
1. Create a repo named `YOUR-USERNAME.github.io` (public) and upload everything in this folder (keep `.nojekyll`).
2. Settings > Pages > Deploy from branch > `main` / root.
3. The site address is already set to https://esraaaibrahimm.github.io (repo name must be `esraaaibrahimm.github.io`). With a custom domain, replace that address everywhere.
4. Submit `/sitemap.xml` in Google Search Console.

## Protecting your data and screenshots
Anything a browser can display can be saved, so protection is layered:
- Screenshots carry a "© Esraa Ibrahim" watermark and are resized (no originals are published).
- The client revenue screenshot (7lw.ae GA4) is NOT published. Add it only with the client's permission.
- Right-click / drag on images is blocked (a deterrent only; screenshots still work).
- `.gitignore` keeps the ZIP, PDF and CV out of the repo. Never commit originals.
- Turn on 2FA for GitHub; keep originals in a private repo or cloud folder.
- Before publishing, check each screenshot for phone numbers, client names or tokens you don't want public.
